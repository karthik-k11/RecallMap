# RecallMap

**A Personal Knowledge & Recall System**

RecallMap is a lightweight, local web application designed to help users organize knowledge, connect related concepts, practice active recall, and track learning progress.

## Planned Features

- Knowledge entry management
- Concept connections
- Active recall questions and answers
- Scheduled review queue
- Learning dashboard
- JSON data export

## Technology Stack

- Python
- Flask
- SQLite
- HTML, CSS, and JavaScript
- pytest
- Git and GitHub

## Project Status

**Day 1 — Project Setup**

The development environment and initial project structure are being prepared. Application features have not yet been implemented.

## Local Setup

1. Clone the repository or open the project directory.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

4. Run the application after the initial implementation is complete.

## Privacy

RecallMap is intended to run locally. The SQLite database and other local data will not be committed to Git.
